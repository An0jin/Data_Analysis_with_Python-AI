# 데이터 분석 및 AI 활용 저장소 (Data Analysis with Python & AI)

이 저장소는 **초등학교, 중학교, 고등학교 학생들에게 데이터 분석 및 AI를 가르치기 위해 구성한 교육용(강의용) 자료**입니다. **MCP(Model Context Protocol)**, **AI**, 그리고 **바이브 코딩(Vibe Coding)**을 활용하여 데이터를 분석하고 각종 숙제 및 프로젝트를 수행한 결과를 모아둔 곳입니다. 나아가 **머신러닝(Machine Learning)** 모델을 적용하여 데이터를 기반으로 한 예측(Prediction)까지 수행하는 것을 목표로 합니다.

## 🎯 주요 목표

- **AI와 바이브 코딩(Vibe Coding) 활용:** 자연어 명령과 AI의 도움을 받아 빠르고 효율적으로 코드를 작성하고 데이터를 분석합니다.
- **다양한 형태의 데이터 분석:** 실제 세상의 다양한 주제(사회 현상, 자연 데이터, 문학 텍스트 등)에 대한 데이터를 수집하고 분석합니다.
- **머신러닝을 활용한 예측:** 단순한 데이터 구조 파악과 시각화를 넘어, 머신러닝 알고리즘을 도입해 결과를 분류(Classification)하고 미래를 예측(Regression)합니다.
- **스마트한 과제 해결:** 복잡한 과제나 데이터 분석 숙제를 AI 에이전트와 효과적으로 협업하여 완성도 높게 해결합니다.

## 📂 프로젝트 목록

현재 저장소에는 다음과 같은 분석 프로젝트(숙제)들이 포함되어 있습니다:

- 🌸 **꽃을 비교해보자**
  - **관련 과목:** 과학 (AI 코딩 교육)
  - **프로젝트 내용:** 아이리스 꽃 데이터를 바탕으로 의사결정나무(Decision Tree) 머신러닝 알고리즘을 활용하여 꽃의 종류를 예측하고 분류합니다. 결정 트리 결과를 로봇 스무고개 형태로 시각화하고 이를 바탕으로 아이리스 분석 보고서(수행평가 결과물)를 완성합니다.
- 📉 **2030년의 대한민국 인구수는?**
  - **관련 과목:** 사회
  - **프로젝트 내용:** 과거 대한민국 남녀 인구수 데이터를 바탕으로 머신러닝 다항 회귀(Polynomial Regression) 모델을 적용하여 2030년의 인구수를 예측합니다. 그래프 시각화를 통해 저출산, 여초 사회 진입 등 사회적 시사점을 분석하고 최종 사회 수행평가 보고서를 도출합니다.
- 📝 **운수좋은날에서 가장많이 나온 단어는?**
  - **관련 과목:** 국어
  - **프로젝트 내용:** 자연어 처리 기법(KoNLPy)을 활용하여 현진건의 소설 '운수 좋은 날'의 텍스트를 형태소 분석하고 불용어를 제거합니다. 핵심 단어들의 빈도수를 막대그래프와 워드클라우드로 시각화하고, 이를 바탕으로 소설의 비극성과 상징적 의미를 분석한 국어 텍스트 마이닝 보고서를 작성합니다.
